# Ivanka v0.1.0-alpha.2 — passing 198-sample benchmark

**Released:** November 11, 2026
**Status:** PASS — current numerical 198-sample updated-MiCall milestone.
**Scope:** Benchmark-qualified experimental alpha; **not** a biological or
clinical release authorization.

This is the next annotated alpha tag after `v0.1.0-alpha.1`.
The release contains the reference-blind, read-supported contig-selection
and 512-nt overlapping tiling implementation merged in PR #213, with
the numerical result and its provenance documented in PR #214. The
AGPLv3 license and optional same-sample read-derived `--seeds` input
are retained. No reference sequences are exposed to the assembler or
candidate selector.

## Acceptance result

The original 198 paired FASTQ samples were evaluated in a single complete,
fresh physical invocation under the same updated-MiCall base for both arms.
All 198 completed without timeout or failure, and each final MAX alignment
score was at least 90% of matched IVA, within the 1,800-second sample cap.

| All-real-`r >= 0` signed-power PSI | Alignment | In-container runtime |
| --- | ---: | ---: |
| Positive for **every** real `r >= 0` | **PASS** | **PASS** |
| Gains / losses / ties | 41 / 9 / 148 | 165 / 33 / 0 |
| `PSI(0)` | 0.161616 | 0.666667 |
| `PSI(1)` | 3.585859 | +27.596477 seconds/sample |
| `PSI(2)` | 193.151515 | 2499.527960 |

The strict verifier returned `real_data_numeric_gate_pass: true` with
zero errors. An independent exact-decimal, descending-magnitude prefix-surplus
certificate also establishes the two **all-exponents** inequalities; no
interpolation or finite selection of exponents is treated as proof.

## Boundaries

The benchmark compares final MAX alignment and complete MiCall runtime,
using the fixed 33-reference panel **only in the independent evaluator and
downstream MiCall**, not inside Ivanka assembly or contig selection.
Passing does not establish full-length haplotype phase, minority-haplotype
recall, or clinical suitability. Those remain separate investigations.

For more detail, see
[`docs/read-backed-selection-experiment.md`](../read-backed-selection-experiment.md).
