# Ivanka v0.1.0-alpha.3 — direct Rust MiCall, physical-198 PASS

**Released:** November 12, 2026
**Status:** **PASS: original 198-sample updated-MiCall numerical gate.**
**Status:** **NOT PASSED: mandatory expanded 598-sample seven-assembler gate.**
**Scope:** Source-attested experimental alpha. Not a clinical/biological
release authorization and **not** a claim that every project intent is met.

This release implements the entire read-backed assembly and postselection
path within native Rust. MiCall invokes the **Rust ELF** directly as
`/usr/local/bin/ivanka`, with `env={}` and only the sample's
`--reads1`, `--reads2`, and `--output` arguments, not Python
wrappers or tuned runtime environments. The default search limits, dominant
read-supported selection, island trimming, and 2,000-nt/512-nt overlapping
tiling are embedded in the assembler. No reference sequence can influence
its output; the fixed 33-reference panel is evaluator/downstream only.

## Original 198-sample physical gate

A **fresh two-arm** updated-MiCall comparison used the unchanged paired
FASTQ manifest, identical base-image layers, the original IVA control, and
the exact native Rust candidate image. Every sample completed with no
disallowed error or timeout; all final MAX alignment scores met the
≥90%-of-IVA per-sample floor. The independent two-arm verifier returned
`real_data_numeric_gate_pass: true`, with zero errors.

this suffices to prove both Ψ(r)>0 for every real r≥0 rather than merely
sampling selected exponents.

## Outstanding mandatory qualification

The enhanced seven-assembler comparison is **not yet passed**. The additional
gate requires all 198 real plus 400 mechanism-diverse synthetic cases,
contrasting Ivanka separately against IVA, Haploflow, MEGAHIT, ABySS, SPAdes
and Velvet, with complete tool provenance, per-sample floors and strict
all-r alignment and runtime Ψ positivity on **both cohorts**. This gate
remains binding, not optional. A successful historical real-only benchmark
cannot qualify the enhanced milestone. Independent held-out validation and
clinical release review are also distinct from either numeric acceptance.
