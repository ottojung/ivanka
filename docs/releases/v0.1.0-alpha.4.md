# Ivanka v0.1.0-alpha.4 — frozen 198-physical benchmark PASS

**Release date:** November 21, 2026  
**Status:** Original **physical 198-sample Ivanka-versus-IVA numerical gate: PASS**.  
**Expanded 198-physical + 464-synthetic seven-assembler gate: NOT PASSED.**  
**Scope:** Native Rust, source-attested experimental alpha. Not a clinical or biological release authorization.

## Frozen physical 198-sample achievement

The original 198 paired-read samples were scored using the source-attested final MiCall MAX local-alignment methodology and the fixed 33-reference evaluation panel (not supplied to Ivanka for assembly). Every Ivanka and every IVA arm finished successfully.

| Physical criterion | Verified result |
| --- | --- |
| Source-attested integrated-MiCall executions | Ivanka **198/198**, IVA **198/198** successful |
| ≥90% of IVA's final alignment, per sample | **198/198 PASS** |
| Strict Ψ(r)>0 for **all real r≥0**, alignment relative to IVA | **PASS**, 55 wins / 14 losses / 129 ties |
| Mean alignment advantage, Ψ(1) | **+3.5858585859** raw alignment points |
| Strict Ψ(r)>0 for **all real r≥0**, runtime relative to IVA | **PASS**, 188 faster / 10 slower |
| Mean runtime advantage, Ψ(1) | **80.8999858143 seconds saved/sample** |
| Ivanka under the 40-minute cap | **198/198**, maximum observed container wall time **577.92 s** |
| Ivanka under 4,000,000,000 B **sampled RSS** | **198/198**, highest sampled process-tree RSS **528,711,680 B** |
| ≥90% of best among all six competing assemblers | **197/198**, one genuine miss: anonymized **R042** (Ivanka 102 vs best 179) |

**Resource qualification limitation:** The resource monitor records sampled process-tree RSS and a 40-minute execution cap; it does not establish independent kernel-enforced hard 4 GB memory isolation. Do not promote older unmeasured comparator runs into qualifying successes.

The all-(r) Ψ claims are computed using the pinned strict decimal signed-power algorithm, not extrapolated from finitely many integer moments. Exact execution and identity evidence remain retained.

## Expanded benchmark: completed, but scientifically not qualified

All **662** source-attested cases (**198 physical + 464 synthetic**) have **seven terminal execution records each** (total **4,634 assembler arms**).

- Synthetic Ivanka: **448/464** successful; all **16 unsuccessful** are from the low-depth family, which fails for all seven assembler-integrated pipelines.
- All-seven-succeeded synthetic subset: **364/464**. On that subset, **47** cases miss the combined-score ≥90%-of-best floor and **68** cases miss the ≥90% floor on at least one required abundant source truth.
- Physical: other assemblers have genuine failures; all seven succeed on **85/198** samples. Ivanka additionally misses the physical best-of-six threshold on R042.
- Consequently the **complete seven-way gate fails**. The independent physical IVA-only PASS does not override failures of other comparators, synthetic abundance-aware accuracy, phase-correctness investigations, or resource-evidence limitations.

The live [Assembler Bench](https://ottojung.github.io/ivanka/bench/) publishes per-sample observed metrics, explicit missing/failure states, cohort-specific comparisons and source provenance. The 15%-abundance synthetic truth methodology and original execution artifacts remain frozen.
